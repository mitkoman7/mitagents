📋 Request Flow Example: "What's the status of my Azure VM?"

1
User sends message via web interface → Flask /chat endpoint
2
LangChain agent receives request with conversation history
3
GPT-4 analyzes intent using function calling: "This is about Azure VM status"
4
GPT-4 selects tool: get_vm_status from 37 available tools
5
Agent calls: get_vm_status_func(vm_name="web-server-01")
6
Function invokes: execute_tool_direct("get_vm_status", {"vm_name": "web-server-01"})
7
Router checks tool name → matches azure_tools list → routes to MCP_AZURE_URL
8
HTTP POST to http://localhost:8086/execute with tool_name and arguments
9
Azure MCP server receives request → authenticates with Service Principal
10
Azure MCP calls Azure Management API for VM instance view
11
Azure API returns VM power state and status details
12
Azure MCP formats JSON response → returns to execute_tool_direct()
13
Result returns to LangChain agent
14
GPT-4 formats natural language response: "The VM web-server-01 is currently running"
15
Flask returns formatted response to user via web interface

🔑 Architecture Patterns

Single Agent Pattern: One LangChain agent orchestrates all 37 tools (not multiple agents)
Microservices: 6 independent MCP servers, each handling specific domain
HTTP Communication: REST API calls between Flask and MCP servers
AI-Driven Selection: GPT-4 automatically chooses the right tool via OpenAI function calling
