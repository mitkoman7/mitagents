app.py
Terminal Bot & AI Agent Client
LangChain Azure OpenAI Pydantic v1
The user-facing terminal interface. Connects to Azure OpenAI (GPT-4o) via LangChain, registers 23+ built-in tools as StructuredTool instances, and dynamically loads evolved tools from the MCP server on startup and after each interaction.
  • main()REPL loop — reads input, invokes agent
  • call_mcp_tool()HTTP POST to MCP /execute endpoint
  • refresh_tools()Hot-loads new evolved tools into the agent
  • create_pydantic_model_from_schema()Builds Pydantic v1 models from JSON inputSchema
  • load_dynamic_tools_on_startup()Loads persisted evolved tools at boot
mcp_server.py
MCP Server & Self-Evolution Engine
FastAPI REST Self-Evolving Persistence
The backend brain. Exposes 23 static tools + unlimited dynamic tools via REST. Contains the Databricks API catalog (7 categories, 30+ endpoints) and auto-generates tool definitions at runtime. Executes SQL via SQL Warehouse (Unity Catalog) with cluster fallback.
  • execute_sql()SQL Warehouse first, cluster fallback
  • auto_generate_tool()Creates tool from API catalog entry
  • execute_dynamic_tool()Runs any evolved tool against Databricks API
  • save_evolved_tools()Persists DYNAMIC_TOOLS to JSON
  • load_evolved_tools()Restores tools from JSON on startup

Request Flow — "Show me tables in dbrmitko.default"

1

User Input

User types "Show me tables in dbrmitko.default" in terminal

2

LangChain Agent Reasoning

GPT-4o analyzes the prompt, matches it to the list_tables tool, and calls list_tables_func(database_schema="dbrmitko.default")

3

HTTP to MCP Server

POST http://localhost:8099/execute with body {"tool_name": "list_tables", "arguments": {"schema": "dbrmitko.default"}}

4

SQL Generation

MCP server builds SHOW TABLES IN dbrmitko.default (detects "." → Unity Catalog format)

5

SQL Warehouse Execution

POST /api/2.0/sql/statements with warehouse_id=adc04bc39671c64d. Parses response from manifest.schema.columns + result.data_array

6

Response Parsing

Extracts table names from rows → {"schema": "dbrmitko.default", "tables": ["hr_attendance_dummy"], "count": 1}

7

User Output

GPT-4o formats the result: "The schema dbrmitko.default contains 1 table: hr_attendance_dummy"

Pydantic v1/v2 Bridge

LangChain internally uses Pydantic v1 for tool argument schemas, but the project installs Pydantic v2. The bridge imports from pydantic.v1 (the compatibility layer) to create models that LangChain accepts:
