🏗️ Architecture Overview

Terminal Bot (app.py)

LangChain Agent with Azure OpenAI. Manages tools and auto-refreshes when evolution occurs.

→

MCP Server (mcp_server.py)

FastAPI server on port 8099. Contains API catalog and dynamic tool registry.

→

Databricks APIs

REST APIs for clusters, DBFS, MLflow, Jobs, Notebooks, and more.

Key Concept: Tools are NOT hardcoded. They are dynamically generated from the DATABRICKS_API_CATALOG dictionary in mcp_server.py. When evolve_discover is called, it reads the catalog and creates tool definitions on-the-fly.

💾 Tool Persistence

Evolved tools are now saved to a JSON file and automatically loaded on server restart.

File Description
databricks/evolved_tools.json Stores all dynamically evolved tools with metadata

Persistence Endpoints

POST /evolve/reload
Reload evolved tools from JSON file
DELETE /evolve/clear
Clear all evolved tools (memory + file)
